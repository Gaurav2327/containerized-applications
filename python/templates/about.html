About This Application

What is this?

This is a simple web application built with Flask, designed to demonstrate containerized application with aws ecs container orchestrator.

Technologies Used

  • Flask - A lightweight WSGI web application framework
  • Python 3 - The programming language
  • HTML/CSS - Frontend markup and styling
  • REST API - JSON-based API endpoints
  • AWS ECR - AWS Container registry service
  • AWS ECS - ECS container orchestration
